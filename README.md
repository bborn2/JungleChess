# Jungle Chess

一个使用 Python 实现的命令行斗兽棋。项目包含棋规、存档、人类对战和一个基于蒙特卡洛树搜索（MCTS）的 AI。

## 运行

需要 Python 3.11 或更高版本：

```bash
python jungle_chess.py
```

选择双人对战或人机对战，按提示输入棋子坐标和目标序号；输入 `q` 可保存当前棋局并退出。

## AI 当前实现

AI 使用 MCTS，而不是 minimax 或强化学习模型。搜索过程反复执行选择、扩展、模拟和回传，并用访问次数最多的根节点子项选择着法。模拟阶段使用简单的吃子/入窝启发式，同时加入随机走法；棋盘搜索使用紧凑表示以加快模拟。

目前没有训练过程、神经网络或从对局中更新的策略。MCTS 只在当前局面进行搜索，搜索结果不会作为已学习的模型保存。

## 用这个项目学习强化学习

可以按以下顺序扩展，逐步把强化学习概念对应到现有代码：

1. **验证环境规则**：`Game.get_moves()` 和 MCTS 使用的 `_fast_moves()` 是两套走法实现。为同一局面比较双方合法着法，并修复差异，避免训练环境与实际游戏规则不一致。
2. **封装环境接口**：保留 `Game` 作为棋规核心，增加 `reset()` 和 `step(action)`。`step` 执行动作并返回观察、奖励、是否结束等信息；命令行交互不参与训练。
3. **定义观察和动作**：将棋盘编码为模型可读的数值状态；动作可编码为起点格和终点格，并提供合法动作掩码，防止策略选出非法着法。
4. **建立基线**：先让随机策略完成对局，再与现有 MCTS 对战，验证状态转移、胜负判断和评估流程。
5. **开始训练**：环境稳定后，可用 Gymnasium 风格接口接入支持离散动作掩码的策略优化算法。先采用终局胜负奖励，再按需要实验奖励塑形。
6. **持续评估**：固定测试局数，记录策略对随机玩家及 MCTS 的胜率。训练奖励本身不能代替实际对战评估。

常用概念映射：`get_moves()` 产生合法动作，`apply_move()` 执行状态转移，`winner` 表示终局；强化学习还需要观察编码、奖励定义和训练循环。
